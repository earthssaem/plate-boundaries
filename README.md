# 판의 경계 탐험 — 움직이는 지구

고등학교 **통합과학 「지권의 변화」** 수업용 웹앱입니다. 발산형·수렴형·보존형 판 경계에서 일어나는 판의 이동, 맨틀 대류, 마그마 상승, 화산 분출, 지진(진원 깊이)을 **3차원 블록 다이어그램** 애니메이션으로 관찰합니다.

`index.html` 한 파일로 동작합니다. 서버 없이 파일을 브라우저로 열거나, GitHub Pages 등에 그대로 올리면 됩니다.

## 장면

| # | 경계 | 예시 | 핵심 관찰 |
|---|------|------|-----------|
| 1 | 발산형 · 해령 | 대서양 중앙 해령 | 맨틀 상승 → 마그마 → 새 지각(나이 줄무늬), 열곡, 천발 지진, 멀어질수록 두꺼워지는 판 |
| 2 | 발산형 · 열곡대 | 동아프리카 열곡대 | 정단층 계단, 지각 박화, 균열 분출과 화산열, 열곡호, 미래의 바다 |
| 3 | 수렴형 · 해양-대륙 | 페루-칠레 해구 · 안데스산맥 | 섭입판, 맨틀 쐐기의 마그마, 산맥 안쪽의 화산, 베니오프대(천발→중발→심발) |
| 4 | 수렴형 · 해양-해양 | 마리아나 해구 · 호상열도 | 가파른 섭입, 해저 화산이 자라 열도가 됨, 베니오프대 |
| 5 | 수렴형 · 대륙-대륙 | 히말라야산맥 | 옛 바다의 섭입으로 바다가 닫힘 → 충돌, 습곡과 지각 뿌리, 화산 없음, 심발 없음 |
| 6 | 보존형 · 변환 단층 | 산안드레아스 단층 | 응력 축적 → 슬립(지진), 어긋나는 도로·하천, 우수향 감각, 판의 생성·소멸 없음 |

주소 뒤에 `#1`~`#6`을 붙이면 해당 장면으로 바로 열립니다 (학습지·수업 자료 링크용).

## 조작

- **탭 / ◀ ▶** 장면 전환, **Space** 재생·정지, **시간 슬라이더** 특정 순간 관찰(정지 상태에서도 대류·연기는 계속 흐릅니다)
- **형성 단계 칩**을 누르면 그 단계의 시작 시점으로 이동
- **시점**: 캔버스를 드래그(↕ 위에서 보기, ↔ 옆에서 보기), 시점 슬라이더, 더블클릭으로 기본 시점. 터치 기기에서는 가로 드래그만 시점에 쓰이고 세로 스와이프는 페이지 스크롤입니다.
- **전체화면** 버튼: 프로젝터·태블릿용
- 체크박스로 지진 / 마그마·화산 / 맨틀 대류 / 이름표 표시 여부 선택

## 과학적 표현에 대한 메모

- **진원 깊이**는 해수면이 아니라 각 장면의 지표·해저면을 기준으로 계산합니다. 화면 옆의 **진원 깊이 눈금**(0 / 70 / 300 km)이 그 기준을 보여 줍니다. 색과 함께 모양(● ◆ ■)도 달라 색각 이상 학생도 구분할 수 있습니다.
- **섭입판**은 해구 바깥의 해양판과 한 몸인, 두께가 일정한 띠로 그려 판이 휘어 들어가는 모습을 보입니다. 마그마는 섭입판 바로 위의 맨틀 쐐기에서 생성됩니다.
- 해령 장면은 가운데 깊은 열곡이 발달하는 **대서양 중앙 해령**(느린 확장)을 예로 듭니다.
- 변환 단층 장면의 ⊗ ⊙ 기호는 각 판의 이동 방향입니다. 보존형 경계에서는 맨틀의 상승·하강을 그리지 않습니다.
- 맨틀 대류가 판을 실어 나른다는 표현은 통합과학 교과서의 모형을 따른 것입니다.

## 개발

```bash
npm install          # playwright 설치
npm test             # 콘솔 오류·이름표 겹침·진원 색 자동 점검 + tests/out/ 에 스크린샷
```

코드 구성(`index.html` 안): 학습 데이터(`INFO`) → 엔진(블록 도형, 지진, 마그마, 이름표, 깊이 눈금) → 장면 함수 6개 → UI·메인 루프.
